# 🤖 What is Prompt Engineering?

Prompt Engineering is the process of designing clear, structured, and effective prompts to guide AI tools in generating high-quality outputs.

Instead of asking general questions, prompt engineering involves:

- Providing task context  
- Defining target audience  
- Setting tone/style  
- Giving output requirements  
- Specifying desired format  

This helps AI generate better and more accurate results.

---

# 🧠 Types of Prompt Engineering Used

## 1️⃣ Zero-Shot Prompting
Giving direct instructions without examples.

**Example:**  
"Generate UGC hooks for a skincare serum."

---

## 2️⃣ Few-Shot Prompting
Providing examples before asking AI to generate outputs.

**Example:**  
Showing sample hooks before generating more hooks.

---

## 3️⃣ Instruction-Based Prompting
Giving structured instructions.

**Example:**  
- Include CTA  
- Keep script under 30 seconds  
- Make it relatable  

---

## 4️⃣ Role-Based Prompting
Assigning a role to AI.

**Example:**  
"Act as a digital marketing expert."

---

## 5️⃣ Constraint-Based Prompting
Adding limitations.

**Example:**  
- Hooks under 10 words  
- Short captions  
- Add emojis  

---

## 6️⃣ Iterative Prompting
Improving prompts step-by-step.

Basic prompt → Improved prompt → Final optimized prompt

---

# 📢 What is UGC Marketing?

UGC (User Generated Content) marketing focuses on creating ads that feel natural and authentic rather than highly promotional.

These ads are commonly used on:

- Instagram Reels 📸  
- Facebook Ads 📘  
- YouTube Shorts ▶️  
- TikTok 🎵
